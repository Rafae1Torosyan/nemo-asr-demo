# NeMo ASR Mini Project

Mini project exploring NVIDIA NeMo for speech-to-text tasks.

## What was done
- Loaded pretrained ASR model (QuartzNet15x5)
- Ran speech-to-text inference on short audio samples
- Explored model configuration and inference outputs

## Tech Stack
- Python
- PyTorch
- NVIDIA NeMo

## Notes
This project focuses on inference and pipeline exploration rather than model training.
